01 / FOCUS

집중력

핵심 의미: 문제를 그냥 지나치지 않고 현상을 확인하며 가능한 원인을 단계적으로 좁혀간다.

[대표 근거] SecuriCare 로그 매핑 트러블슈팅 개요

• 문제: Suricata와 WAF에서 수집된 보안 로그가 Elasticsearch로 전달되었지만 Kibana에서 특정 필드가 누락됨.
• 분석: Elasticsearch 인덱스 구조와 로그 필드를 단계적으로 비교·분석.
• 원인: 로그 데이터 타입과 Elasticsearch Mapping 간 충돌이 발생함.
• 해결: Filebeat 설정과 로그 수집 Pipeline을 수정하고 데이터 구조를 재정의함.
• 결과: 새 인덱스에서 로그가 정상적으로 수집되고 Kibana 대시보드 시각화가 복구됨.
"문제를 그냥 지나치지 않고 현상을 확인하며 가능한 원인을 단계적으로 좁혀간다."

  • 어디로 가나요: 상단 네비게이션 및 각 섹션 (FOCUS, SYSTEM, COMM, PROJECT, TS)
  • 3단계 이내 무엇을 하나요: 페이지 접속 ➔ 상단 메뉴 클릭 또는 스크롤 ➔ 카드 및 토글 상호작용 확인

3. AI와 나의 판단

  • AI에게 맡긴 일: Pretendard 폰트 스택 적용, 3단계 섹션 위계 스타일 분리 및 SVG 아이콘 통합
  • 직접 판단한 일: 보안 실무 서사 및 다크 반전 Hero 섹션과 보조 Tier 3 섹션 간의 시각적 흐름 조율
  • AI 제안 안 따른 일: 기본 플로팅 대신 페이지 흐름을 방해하지 않는 하단 토글 구조를 채택하여 과제 증빙 메타정보를 깔끔하게 분리함
